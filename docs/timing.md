# 理论滞后与未来等待

[算法索引](overview.md) · 实现：[timing.py](../tslab/timing.py)

A01 离线曲线下方新增理论时间表；模拟实时在原状态表加入低频滞后（帧、秒）及适用范围。仅描述信号平滑，不将这些零阶值直接套用于 A07 的求导算子。

## 定义

对线性时不变滤波器，群延迟（样本）为 τg(ω)=−d arg H(exp(jω))/dω。页面显示 ω→0 的低频极限，秒数为该值乘 Δt。它适合描述缓慢变化/低频窄带包络的近似延迟，不是任意峰值的平移量。单个正弦的相位延迟 −arg H/ω 与群延迟不同，低频极限才可能一致。

值以曲线标注的“被估计时刻”为参照。未来等待是该估计何时能发布：例如五点中心 SG 表中低频滞后为 0，但仍要等 2 帧。计算耗时、启动帧数也不包含在低频滞后内。空值不代表零。

## 当前计算

| 方法 | 低频等效滞后（样本） | 限制 |
|---|---|---|
| 后向 MA | (W−1)/2 | 完整窗口内部 |
| EMA | (1−α)/α | 稳态；adjust=True 的启动归一化阶段不同 |
| 单边 Gaussian | Σ k w_k，k 是历史距离 | 根据当前 σ 和截断窗口计算 |
| 中心 MA / SG / Gaussian | 0 | 目标时刻对齐；未来等待仍为半窗口/核半径 |
| SG-endpoint | 0 | 当前界面 p≥1；只保证低频极限，不保证全频率零相位 |
| 单向 Butterworth | 由 SOS 各节零频相位导数相加 | 随频率变化，页面只列零频极限 |
| 双向 Butterworth | 0 | 理想内部零相位；全段离线，未来等待没有固定帧数 |
| Kalman | (1−K∞)/K∞ | 仅当前标量随机游走的渐近稳态 |
| LOWESS | 不适用 | 邻域与稳健残差权重数据相关，无统一固定值 |

Butterworth 每节分子 b、分母 a 的零频群延迟为 `(b1+2b2)/Σb − (a1+2a2)/Σa`，采用实际数字滤波系数求和，而非套用模拟原型。默认 fs=10 Hz、fc=1 Hz、N=2 时约 2.176 样本，即 0.218 秒；这不表示每个频率都恰好落后这个时间。

Kalman 在 Q>0 时，预测稳态方差 S=(Q+sqrt(Q²+4QR))/2，K∞=S/(S+R)。启动增益不同；Q=0 时不提供有限固定稳态滞后。

## 双向滤波为何不用于当前实时模拟

反向滤波需要从记录末端向前处理，新到达数据会改变先前估计。当前模拟遵守“已发布结果不回写”，不能直接使用全段双向实现。可以另设计缓冲窗口/固定延迟近似，但它是不同的算法，不等同于完整记录上的 sosfiltfilt。

双向内部幅度响应为 |H|²：单向某频率幅度保留 0.5，双向保留约 0.25；截止点从约 −3 dB 变为 −6 dB。没有相位偏移不表示信号完全不变。

边界处缺少记录外的数据，只能使用延拓与初始状态假设。项目用奇对称延拓；若假设与实际信号不符，首尾可能偏差、过冲或振荡。延拓长度不是确定的污染范围；边界影响随截止频率、阶数与数据而变化。

校验：Butterworth 零频结果与 SciPy group_delay 对照，另检查 MA、EMA、Gaussian 矩及不适用项。
