# A06：频谱分析与干扰抑制

## 概念与目标

时域表示“数值如何随时间变化”，频谱表示“各频率成分有多强”。FFT 是高效计算离散傅里叶变换（DFT）的算法，不是 Butterworth 的一种形式，也不自动判断哪些成分是干扰。

- FFT / 幅度谱：帮助观察频率成分。
- Butterworth：按截止频率与阶数设计低通/高通/带通/带阻滤波器；本身不执行频谱分析。
- 陷波（notch）：专门削弱选定频率附近的窄带振荡。
- 滤波抑制不同于已知干扰波形的精确相减。若同频率上既有目标又有干扰，单通道频率选择通常不能分离它们。

## 分步实现

### 第一步：频谱观察

建立 A06 的离线页面，使用“目标正弦 + 干扰正弦 + 随机噪声”的可控合成数据，支持频率、幅度、采样率和记录长度。场景标签明确哪些是目标、哪些是干扰，不能把最大谱峰自动认作噪声。

显示时域观测/目标真值，以及单边幅度谱。用 `scipy.fft.rfft` 和 `rfftfreq`；说明默认去均值、Hann 窗及幅度校正。峰值候选仅供参考，用户选择要抑制的频率。配套创建 `docs/fft.md`。

验收：已知整频点正弦的频率与幅值、奇偶长度下 DC/Nyquist 不重复加倍、记录长度与频率间隔、非整频点泄漏。窗函数校正不保证非整频点峰值恰好等于真实幅度。

### 第二步：选择频率并抑制

加入 Butterworth 低通和 IIR 陷波作为对照：低通演示整体削弱高频，陷波演示只削弱指定窄带。分别创建 `docs/butterworth.md`、`docs/notch.md`。

候选调用：`butter(..., fs=fs, output="sos")`，`iirnotch(f0, Q, fs=fs)`。先提供单向因果计算；双向离线形式另作独立变体说明，明确幅频响应平方和边界效应，不只是“去掉延迟”。

页面给出时域前后对比、同尺度幅度谱及滤波器频率响应。后者是滤波器对不同频率的增益，不能与某段数据的频谱混淆。指标关注目标频率保留、干扰衰减和有真值 RMSE；若按频带积分评价，需要使用具有一致单位的功率谱定义，不能拿幅度谱直接充当 PSD。

验收：截止/陷波频率严格位于 (0, fs/2)，Q 和阶数有效；短数据、启动瞬态、目标与干扰接近时的误伤都有说明。

### 第三步：模拟实时与已有板块复用

复用手动进度控件；因果滤波只处理已到达数据，频谱也只能使用已到达的前缀或明确的历史窗口。频率识别需要观察时长，这与滤波本身是否等待未来帧不同。双向全段滤波不能放入实时无等待组。

验证后再将低通方法复用到 A01，并按明确的求导规则接入 A07；不在同一小步同时扩展所有页面。

## 界面与限制

保留单一工作区：场景参数 → 时域曲线 → 频谱 → 滤波方法与参数 → 结果/指标。不增加自动播放；未实现的模拟入口不做空壳。首版不加入时频图、频率跟踪、自适应消噪或 FFT 频点硬清零。

- 采样率 fs=1/Δt，最高可辨范围受 Nyquist 频率 fs/2 限制；混叠后不能靠 FFT 恢复真实高频。
- DFT 频率间隔为 fs/N；补零可加密频谱网格，但不增加记录实际分辨相近频率的能力。
- 去均值影响 DC，加窗改变幅度与峰宽；必须标明使用方式。
- 全段频谱不能说明某个频率在何时出现；随时间变化的频率留待后续 STFT 等方法。
