# 阶段 1 检查说明

本阶段完成 A01 随机降噪与稳定读数，尚未进入导数或其他应用板块。

## 页面与功能

- 左侧只显示已实现的 A01；右侧依次为数据、模式、算法选择、折叠参数、曲线与指标。
- 保留五个内置数据集，增加正弦、缓慢趋势和恒定读数三个带真值场景；可设置采样间隔、样本数、噪声和随机种子。
- 原有六种算法全部可用，新增后向 MA。默认选择 EMA 与 Kalman；只有选中的方法才执行计算。
- “仅因果方法”只提供后向 MA、EMA、Kalman，表示对已有记录进行因果计算，尚未接入实时设备。
- 合成场景显示原始信号、真值、估计，以及 RMSE、MAE、RPR；内置 CSV 无干净真值，不展示恢复误差。
- 算法说明包含未来信息使用、边界处理与初始化影响。当前不自动估计响应延迟，也没有固定延迟回放。

## 相对原项目的明确变化

1. **MA 边界**：居中 MA 不再回填首尾值；完整窗口之外返回 NaN，在图中保留空缺。内部结果与历史基线一致。后向 MA 的启动区同样不回填。
2. **Gaussian 整数输入**：原始太阳黑子数据为整数，旧调用继承整数输出类型而截断小数。现在统一使用浮点计算；测试验证旧整数基线等于新结果截断后数值，同时验证整数脉冲不会被滤成全零。
3. **EMA**：默认仍为 `adjust=True`；提供显式开关，可选择固定系数递推。
4. **Kalman**：默认数值不变，将原先的 `std` 标签修正为方差 Q、R，不偷偷平方参数。
5. **SavGol**：窗口受数据长度约束，多项式阶数必须小于窗口；缩短数据或窗口时，相关控件随之收缩。
6. **LOWESS**：标签明确使用 LOWESS；保留三次稳健迭代，邻域至少包含两个点。
7. **指标**：所有选中输出及原始观测在相同的有限值点集合上评价；RPR 只使用其中实际相邻的有效点对，不跨越空缺。选择不同方法可能改变共同评价区间，因此显示有效点数。其他方法的边界拟合点和初始化区域仍纳入指标，不宣称消除了边界影响。

所有默认结果除上述 MA 边界及整数 Gaussian 修正外，均与阶段 0 的五个数据集基线在 `rtol=atol=1e-10` 内一致。快照文件未改写。

## 建议人工检查顺序

1. 打开 `http://127.0.0.1:8501`，检查默认布局与原始信号/真值/算法输出是否容易区分。
2. 勾选 SavGol 或居中 MA，调节窗口；观察曲线和误差是否同步变化。
3. 切换“仅因果方法”，确认仅有后向 MA、EMA、Kalman。
4. 切换内置数据集，确认没有 RMSE/MAE；切回合成信号，选择恒定读数并将噪声设为零，确认 RPR 显示空值。
5. 缩短数据、取消全部算法，检查提示是否清晰。
