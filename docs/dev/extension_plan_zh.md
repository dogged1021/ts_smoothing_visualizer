# 时间序列滤波与特征估计：应用分类及扩展规划

本文用于指导项目的后续扩展，是规划文档，不表示所列功能已经全部实现。当前已完成 A01：MA（居中/后向）、EMA、Savitzky–Golay、LOWESS、Gaussian 和一维 Kalman 的平滑对比，并支持带真值的合成场景与任务指标。A07 首版也已实现直接差分、EMA/Gaussian 平滑后差分和 SavGol 直接求导，支持解析真值与逐阶误差。其余应用仍按 [开发计划](development_plan_zh.md) 逐步推进。

具体实施顺序、首版范围和模块划分见 [开发计划](development_plan_zh.md)。本文中的优先级表示功能重要性，逐步交付顺序以开发计划为准。

## 1. 分类原则

以“用户想得到什么结果”为一级应用板块，以“实时、延迟输出或离线”为执行模式，以算法原理作为说明标签。同一算法可复用于多个板块，不需要为每个板块重复实现。

每次实验应明确四件事：

1. 目标量：干净信号、趋势、导数、事件、频段、状态或累计量。
2. 干扰与假设：随机噪声、异常点、基线漂移、周期干扰，以及采样是否均匀。
3. 信息范围：只用过去和当前，允许有限未来窗口，或使用完整序列。
4. 成功标准：目标量误差、结构保留、响应延迟，以及不确定性是否可信。

不要用“越平滑越好”统一评价所有板块。实时与离线结果可同时展示，但必须明确标记，不能隐去未来信息带来的优势。

## 2. 需要补充的应用视角

之前的分类偏重恢复信号幅值，遗漏了由信号推导出的量及后续分析任务。

| 信息层面 | 用户关心的结果 | 对滤波与平滑的额外要求 |
|---|---|---|
| 幅值与形态 | 信号值、峰高、峰宽、阶跃 | 降噪且不过度扭曲结构 |
| 一阶、二阶及更高阶导数 | 变化率、速度、加速度、拐点 | 控制求导造成的噪声放大，保留导数的符号和量级 |
| 积分与累计量 | 面积、累计流量、累计能量、位移 | 控制偏置和漂移，检查边界与基线处理 |
| 时间与事件 | 峰值时刻、阈值越界、起止点、变化点 | 关注事件定位误差、漏检、误报和报警延迟 |
| 频率与尺度 | 周期、频带能量、包络、相位 | 检查频率选择性、相位失真和多分量混叠 |
| 隐状态及多通道关系 | 位置与速度联合估计、传感器融合 | 使用动力学、通道间相关性及观测可信度 |
| 数据完整性 | 缺失区间、非均匀时间戳、采样率转换 | 明确插补假设、时间尺度、抗混叠和信息泄漏 |
| 可信度 | 状态方差、区间覆盖、残差结构 | 平滑曲线本身不等于估计可靠 |

一阶、二阶导数属于微分信息；它们与偏度、峰度等“高阶统计量”不是同一概念。局部方差、RMS、偏度、峰度可作为后续特征分析功能，初期不必各自设为滤波板块。

## 3. 应用板块与代表性算法

优先级：P1 为首批核心功能；P2 为第二阶段；P3 为进阶功能。每个板块先实现少量具有代表性的基线与方法，不追求一次覆盖所有算法。

| ID | 应用板块与目标输出 | 代表性算法或处理流程 | 当前基础 | 优先级 |
|---|---|---|---|---|
| A01 | 随机噪声抑制与稳定读数：输出干净信号估计 | 后向/居中 MA、EMA、Gaussian、Butterworth 低通、Kalman | MA、EMA、Gaussian、一维 Kalman | P1 |
| A02 | 趋势、基线与周期成分分离：输出趋势、去趋势结果或分解分量 | LOWESS、平滑样条、Whittaker；非对称最小二乘基线；STL 周期分解 | LOWESS 等可复用 | P1 趋势；P2 基线与分解 |
| A03 | 孤立毛刺与异常观测修复：输出修复信号及修改掩码 | 中值滤波、Hampel、稳健局部回归 | 当前 LOWESS 带稳健迭代 | P1 |
| A04 | 峰形与瞬态波形保真：输出保形降噪信号 | Savitzky–Golay、Gaussian 基线、小波阈值去噪 | SavGol、Gaussian | P1；小波 P2 |
| A05 | 阶跃与工况边界保留：输出分段信号估计 | 中值滤波、TV 去噪、变化点分段后平滑 | 暂无专门方法 | P2 |

| A07 | 导数与变化率估计：输出一阶、二阶导数及可选的信号估计 | 有限差分基线、先平滑后差分、SavGol 直接求导、高斯导数、平滑样条求导、运动模型 Kalman | 已实现差分、EMA/Gaussian 后差分、SavGol 求导；高斯导数核与状态模型待扩展 | P1 基线与 SavGol；其他 P2 |
| A08 | 事件与关键时刻提取：输出峰、零交叉、拐点或变化点 | 固定检测器前接不同滤波器；峰显著性检测、迟滞阈值、CUSUM | 暂无 | P2 |
| A09 | 隐状态跟踪与多传感器融合：输出状态和方差 | 一维 Kalman、位置—速度/位置—速度—加速度 Kalman、RTS smoother；多观测 Kalman、EKF/UKF | 一维随机游走 Kalman | P2 线性状态；融合与非线性 P3 |
| A10 | 包络、局部能量与瞬时频率：输出幅度包络、RMS、相位或频率 | 滑动 RMS、整流后低通、带通后 Hilbert 解析信号、相位平滑与差分 | 暂无 | P3 |
| A11 | 累计量与积分保真：输出累计积分及终点总量 | 梯形积分基线、去基线/降噪后积分、状态空间积分估计 | 暂无 | P2 |
| A12 | 缺失修复与采样转换：输出重建序列或新时间网格 | 线性/PCHIP 插值、平滑样条、Kalman 缺失观测处理、多相抗混叠重采样 | 暂无 | P3 |

A08、A10、A11、A12 是滤波的下游或配套任务，不应全部称为“滤波算法”。项目可以比较完整处理流程，但应标明每一步职责。

一些边界条件：

- A02：趋势不等于背景基线。具有大量正向峰的信号，普通对称平滑可能把峰当作基线，应单独比较基线估计方法。STL 适用于有明确周期设定的序列，不是通用去噪器。[STL 文档](https://www.statsmodels.org/stable/generated/statsmodels.tsa.seasonal.STL.html)
- A03 与 A08：如果毛刺正是要检测的故障，修复会删除目标信息。场景必须先标明哪些异常是干扰、哪些是目标事件。
- A05：TV 倾向于分段常数，可能把光滑斜坡变成台阶；这也是需要展示的失败案例。
- A09：当前随机游走 Kalman 不直接提供速度或加速度；必须扩展状态和转移模型。EKF/UKF 只有在非线性模型场景下才有相应比较意义。
- A10：Hilbert 包络与瞬时频率应优先在单分量或经过频带隔离的振荡上演示；多分量叠加和接近零的幅度可能使解释失效。[Hilbert 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.hilbert.html)
- A12：插值不能凭空恢复缺失的真实细节；降采样需要先抑制将产生混叠的频率成分。[多相重采样文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample_poly.html)

## 4. 导数估计板块的具体规划

### 4.1 为什么必须独立评价

设观测为 y(t) = s(t) + 噪声。信号值 s(t) 估计得不错，并不保证 s′(t) 或 s″(t) 估计得好。

以等间隔、独立同方差噪声为例，前向一阶差分的噪声方差是 2σ²/Δt²，三点二阶差分是 6σ²/Δt⁴。直接差分会放大噪声；提高采样率本身不保证这些导数估计更准。频域中，k 阶微分对应乘以 (jω)^k，进一步说明了对高频噪声的敏感性。

“先平滑，再求导”是一条处理路线，但不是唯一方法。局部多项式、样条和状态模型可以直接估计导数或相应状态。

### 4.2 首批对比路线

| 路线 | 作用与假设 | 参数/模式 | 需要揭示的问题 |
|---|---|---|---|
| 原始有限差分 | 提供未经降噪的基线 | 后向/中心差分、真实时间坐标 | 噪声放大；中心差分需要未来点 |
| 平滑后有限差分 | 展示串联处理的影响 | EMA/MA/Gaussian + 差分 | 幅值平滑合适的参数未必适合导数；可能有滞后 |
| SavGol 直接求导 | 从局部多项式获得导数 | 窗长、多项式阶数、deriv、delta | 窗长必须大于多项式阶数；多项式阶数至少覆盖导数阶数，最好留有拟合余量 |
| 高斯导数 | 在指定尺度上估计变化 | sigma、导数阶数 | 尺度决定可见细节；按样本单位得到的 k 阶结果需换算为时间单位 |
| 平滑样条求导 | 拟合可微曲线后取导数 | 平滑强度、实际时间坐标 | 插值样条并不自动降噪；端点导数敏感 |
| 运动模型 Kalman | 联合估计位置、速度、加速度 | 状态模型、Δt、Q、R；filter/smoother | 动力学假设不匹配会带来偏差；更高维状态不保证更好 |

SciPy 的 `savgol_filter` 已提供 `deriv` 和样本间距 `delta`；`gaussian_filter1d` 的 `order` 可指定高斯导数。因此可复用现有依赖扩展这两条路线。[SavGol 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.savgol_filter.html) · [Gaussian 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.gaussian_filter1d.html)

### 4.3 时间、单位与真值

- 使用真实的 Δt；若输入单位是米、时间单位是秒，则一阶、二阶输出分别为 m/s、m/s²。
- 标准 SavGol 的单个 `delta` 适用于均匀采样。非均匀采样应采用基于实际时间坐标的局部多项式/样条，或明确说明重采样步骤。
- 二阶导数可帮助判断凹凸性及拐点，但不等同于几何曲率；拐点还需检查符号变化和稳定性。
- 以解析正弦、多项式、光滑峰、光滑变频信号提供 s、s′、s″ 真值，不要对带噪观测差分后充当真值。
- 阶跃处经典导数不存在，不应在那里计算普通点值导数误差；应排除不连续点附近的指定区域，或另行评价变化点定位。
- 初期仅支持 0、1、2 阶，三阶及以上留作扩展；阶数越高越依赖平滑和模型假设。

### 4.4 可视化与指标

三行共享时间轴：信号、一阶导数、二阶导数。各行展示真值、基线、所选方法；可选误差面板。标记端点影响区、无效点和未来窗口。

分别报告各阶 RMSE/MAE、有效样本数、边界与内部误差；可选导数符号准确率、极值/拐点定位误差、延迟。导数接近零时，不采用逐点相对误差作为主指标。幅值平滑与导数估计可以使用不同最优参数。

执行约定：

- 合成实验提供干净真值、固定随机种子、噪声类型与强度。进阶比较使用多个随机种子，展示误差分布。
- 真实数据无真值时，指标只能说明粗糙度、残差、频谱等性质，不宣称真实恢复精度。
- 不同量纲的误差分开展示。不给所有板块设置未经论证的统一总分。
- 同窗口长度不等于同平滑强度；可比较“误差—延迟”或“降噪—结构失真”曲线，说明参数范围。
- 事件对比先固定检测器及匹配容差，仅替换预处理方法，避免混淆滤波与检测器的影响。
- 区分等待未来样本的延迟、波形响应滞后和计算耗时。非线性方法不强行使用线性时不变系统的频率响应解释。
- 若为了诊断做时间对齐，同时报告未对齐误差与估计滞后，不能通过对齐隐藏实时延迟。
- 区间只在方法确实提供并说明假设时展示；Kalman 模型方差不自动等于经过验证的置信度。

## 6. 统一使用模式与界面规划

使用模式是全局筛选项，不替代应用板块：

| 模式 | 可用信息 | 示例 |
|---|---|---|
| 实时因果 | 过去与当前；初始化和参数估计也不得使用未来观测 | 后向 MA、EMA、单向 IIR、Kalman filter |
| 固定延迟 | 允许未来 L 个点，需要等待 L 个采样间隔 | 居中有限窗口、固定滞后状态平滑 |
| 完整离线 | 可使用整个记录 | 全局样条、双向滤波、Kalman/RTS smoother |

固定延迟只意味着未来信息范围受限，不保证幅度或相位无失真；离线零相位处理也可能存在边界效应和幅度变化。

建议每个板块采用同一页面顺序：目标说明 → 场景/数据 → 使用模式 → 算法与参数 → 目标量对比图 → 误差/诊断 → 方法假设与失败案例。

共享元信息包括：时间单位、采样间隔、缺失处理、参数、输出单位、边界策略、未来样本使用量和有效区间。某方法不适用于所选采样或模式时，应明确显示原因。

未来实现可复用“数据生成、算法计算、绘图、评价”四部分。计算结果除信号外，还应能携带导数、分量、状态、事件、方差和有效掩码；不要求每个方法都输出所有字段。

## 7. 原始项目与扩展前的检查项（阶段 0 记录）

以下记录阶段 0 的原始 `app.py`，用于说明改动依据；已完成修正见 [阶段 1 检查说明](stage1_review_zh.md)。

| 当前实现 | 后续应明确或修正的行为 |
|---|---|
| MA 为 `center=True`，并用 bfill/ffill 补边界 | 标记未来信息；边界填充值不可误当同质量估计；增加后向版本 |
| EMA 未指定 `adjust` | 明确保留默认归一化权重，或提供经典递推版本；标签与公式一致 |
| SavGol 仅输出 0 阶 | 增加导数阶数与真实 Δt；校验窗口、多项式阶数和序列长度 |
| LOESS 标签对应 `lowess` | 说明局部线性拟合与默认稳健迭代；`frac` 是样本比例，记录长度改变会改变有效窗口 |
| Gaussian 默认按样本尺度平滑 | 显示 sigma 的样本/时间单位，明确边界与截断策略 |
| Kalman 仅一维随机游走，调用 `filter()` | 与高维运动模型、`smooth()` 分别命名；不能把现有输出当速度/加速度 |
| Kalman 滑块标为 std，却直接传给 covariance | 后续选择“输入标准差并平方”或“输入方差并改标签”，避免参数单位混淆 |
| 大部分方法按行号处理，时间戳主要用于展示 | 导数、频率和动态模型前先检查时间顺序、重复时间戳及采样均匀性 |
| 只有 RPR 粗糙度比例 | 保留为辅助指标；补充应用指标；常数原序列的分母为零需处理 |

Kalman 的滤波、平滑和协方差接口定义见 [PyKalman 文档](https://pykalman.readthedocs.io/en/latest/class_docs.html)。具体 API 和依赖可用性应在实施时以 `ts_filter` 环境中的实际版本核验；本阶段没有修改环境。

## 8. 分阶段实施建议

### 第一阶段：建立核心比较能力

先建立真实时间轴、使用模式、带真值的合成数据、有效区域和按任务评价机制，再实现 A01、A02 趋势、A03、A04、A06 基础、A07 基础。

代表算法集合：现有六种方法，加后向 MA、中值、Hampel、Butterworth、陷波、有限差分、SavGol 求导。优先复用 NumPy、SciPy、Pandas、Statsmodels 和 PyKalman。

完成标准：每个首批板块至少有一个带真值场景、一个基线和一个对照方法；明确模式和参数单位；能够看到方法的优势与失败情形。A07 至少同时显示一阶与二阶结果并分别评价。

### 第二阶段：结构、动态与下游任务

扩展 A02 基线/周期、A05、A08、A09 线性状态、A11；加入样条、Whittaker、TV、小波、STL、运动模型 Kalman 与 RTS 平滑。同步补充事件、面积、边界及状态不确定性评价。新增依赖和数值实现逐项选择，不一次引入所有候选库。

### 第三阶段：复杂数据与进阶应用

加入 A10、A12、多通道融合、非线性状态估计；按需要扩展参考通道驱动的 LMS/RLS 自适应干扰消除。后者需要与干扰相关的参考输入或明确的辨识结构，不能作为无条件的单通道通用降噪按钮。

预测、控制、反卷积和领域专用诊断暂不作为核心板块；它们需要额外模型和评价体系。若未来明确有需求，再沿“目标输出—假设—使用模式—指标”的结构扩展。

A06 将按 [频谱观察、滤波抑制与模拟实时的分步规划](frequency_plan_zh.md) 推进；FFT 是分析计算工具，Butterworth 和陷波是频率选择方法，不混为一种算法。
